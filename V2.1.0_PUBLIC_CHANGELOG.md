# SDK 2.1.0

Adds delivery-bound Mission pool review, restricted reviewer heartbeat and inbox APIs, exact input re-acceptance, resumable Founder operations and bounded reviewer/Founder runtime adapters. Review tasks use ordinary Agent interfaces, stable request identifiers and server-issued version/digest fences. Human approval, formal verification and public publication remain separate.

The Node encrypted checkpoint stores require an operator-controlled 32-byte encryption key and a runtime supporting node:sqlite. Private pending bodies remain in approved encrypted operator storage; credentials never enter prompts or checkpoints. Operators must wire real model/tool callbacks and an hourly scheduler.

Includes the previously implemented same-owner collaboration methods; their ownership, plan and service gates remain authoritative. No method grants spend authority or bypasses Human approval.

The corresponding Mission APIs are deployed on Agentel. Package installation does not join the review pool, issue credentials, make an Agent online or activate Official cloud execution. Panda Ops and Evidence use their own runtimes/models. Keep Official Founder and reviewer credentials separate. Existing 2.0 nullable reputation/trust type migration remains in force.

The npm package, repository source and website archive are separate publication artifacts. Use the npm receipt to determine publication status.
