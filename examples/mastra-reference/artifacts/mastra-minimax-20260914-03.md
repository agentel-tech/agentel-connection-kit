# Mastra Templates - Research Summary

## Summary

Mastra Templates are ready-to-use starter kits designed for AI agent builders. The platform provides working examples of agents, workflows, and MCP (Model Context Protocol) servers that developers can clone and customize. The templates cover a diverse range of use cases including research assistants, document processing, code review, customer onboarding, and integration with popular tools like Slack, GitHub, YouTube, and Google Sheets. Each template includes a quickstart guide and can be scaffolded locally, with integration options for React, Next.js, or Vue applications via the Mastra Client SDK or AI SDK UI libraries.

## Key Facts

**Template Categories:**

- **Research & Analysis Agents:** Deep Search, CSV to Questions Generator, Customer Feedback Summarization
- **Document Processing:** Chat with PDF, Flash Cards from PDF, Docs Chatbot
- **Browser & Web:** Browser Agent (integrates Stagehand), Chat with YouTube
- **Database & Sheets:** Chat with Database, Google Sheet Analysis
- **Business Workflows:** Security incident triage and response, KYC and Customer Onboarding, Accounts Payable Automated Invoice Processing
- **Developer Tools:** GitHub PR Code Review, Agent Harness (local workspace, shell tools, memory, task tracking), Agent Builder (visual editing interface), Mastra Code (terminal-based coding agent)
- **Communication:** Slack Agent
- **MCP Servers:** Template for building MCP servers and connecting to Mastra agents

**Getting Started:**

- Templates include quickstart guides in their repositories
- New projects can be created via: `npm create mastra@latest <project-name> -- --llm <provider>`
- Dev server starts with: `npx bgproc start -n <project-name> -w -- npm run dev`
- Mastra Studio available at `http://localhost:4111`

**Integration Options:**

- React, Next.js, Vue via Mastra Client SDK
- AI SDK UI, CopilotKit, and Assistant UI libraries supported

**Community:**

- Template contributions welcome from the community
- Templates live in the Mastra monorepo and auto-sync to standalone repositories
