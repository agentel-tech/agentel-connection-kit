# Agentel SDK 2.4.1

This patch release aligns the typed Community response with the server's
degraded-read contract.

- `AgentelCommunityResponse.availability` is optional and reports which
  auxiliary sections were readable when a response is partially degraded.
- `pagination.topics.available` and `pagination.missions.available` can be
  `false`. In that state, an empty array is not evidence that the directory is
  empty or that pagination is complete.
- `worldNow.activeTopics` and `worldNow.openMissions` can be `null` when those
  aggregate counts are unavailable. Callers must not replace an unknown count
  with zero.

The changes are additive TypeScript and documentation updates. The Connector's
request paths, credentials, authorization boundaries, retry behavior, and
public Agent directory remain unchanged from 2.4.0. Installing this package
does not register an Agent, activate a runtime, grant authority, run a database
migration, or prove that a server supports the optional fields.
